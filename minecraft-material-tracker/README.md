# Minecraft Material Tracker

Bloxelizer が出力する CSV または TXT 形式の素材リストを読み込み、Minecraft の建築に必要な素材の収集状況を効率よく管理する Web アプリケーション。

## 特徴

- **CSV/TXT インポート**: Bloxelizer の出力ファイルを直接インポート
- **進捗管理**: 各素材の収集状況をリアルタイムで追跡
- **レイヤー管理**: 建築レイヤー別の進捗を確認
- **オフライン対応**: IndexedDB を使用してオフラインでも作業可能
- **クラウド同期**: Supabase を使用してデータをクラウドに保存（設定時）
- **マルチプレイ対応**: 複数人での共同収集をサポート

## 技術スタック

- **フロントエンド**: React + Vite + TypeScript
- **UI**: Tailwind CSS
- **データベース**: 
  - ローカル：IndexedDB
  - クラウド：Supabase PostgreSQL
- **認証**: Supabase Auth（準備中）

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定（Supabase 連携時）

`.env.example` をコピーして `.env` ファイルを作成し、Supabase の認証情報を設定します。

```bash
cp .env.example .env
```

`.env` ファイルを編集：

```
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

### 4. ビルド

```bash
npm run build
```

## 主な機能

### プロジェクト管理

- 新規プロジェクト作成
- CSV/TXT インポート
- CSV 再インポート（設計変更対応）
- プロジェクト一覧
- プロジェクト削除
- 自動保存

### 素材管理

- 素材名、必要数、所持数、不足数の管理
- スタック数・シュルカーボックス換算
- レイヤー情報
- アイテム ID
- 進捗率表示

### 入力方法

- `+1` / `-1` ボタン
- `+64` / `-64` ボタン
- 数値直接入力

### ダッシュボード

- 全体進捗
- 必要素材総数
- 所持素材総数
- 不足素材総数
- 完了素材数
- 未完了素材数
- 建築完成率

### レイヤー管理

- レイヤー別素材一覧
- レイヤー別進捗
- レイヤー選択によるフィルター

### 検索・フィルター

- 素材名・アイテム ID で検索
- 不足のみ/完了のみ/未完了でフィルター
- レイヤー別フィルター
- ブロック種類別フィルター
- 並び替え（名前、必要数、不足数、レイヤー）

### CSV 差分更新

新しい CSV を読み込んだ際：

- 所持数を維持
- 必要数を更新
- 削除された素材を表示
- 新しく追加された素材を表示

### スタック換算

自動計算：

```
1523 個 → 23 スタック 51 個
シュルカー：0.85 箱
```

## データベース構造

### projects テーブル

- `id`: UUID
- `user_id`: ユーザー ID
- `name`: プロジェクト名
- `created_at`: 作成日時
- `updated_at`: 更新日時

### materials テーブル

- `id`: UUID
- `project_id`: プロジェクト ID
- `item_id`: Minecraft アイテム ID
- `name`: 素材名
- `required_count`: 必要数
- `owned_count`: 所持数
- `layer`: レイヤー
- `stack_size`: スタックサイズ
- `type`: ブロック種類

## オフライン対応

このアプリケーションは IndexedDB を使用してローカルにデータを保存するため、インターネット接続がない場合でも以下の機能が利用可能です：

- プロジェクトの閲覧
- 素材の収集状況の更新
- CSV のインポート

オンラインになった時点で、Supabase との同期が可能です（設定時）。
